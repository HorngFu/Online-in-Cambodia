# Security Policy

## Reporting a vulnerability

**Please do not report security issues in public issues.**

Use GitHub's private vulnerability reporting instead:
**Security** tab → **Report a vulnerability** (or go to `/security/advisories/new` on this repository).

Please include:

- What the issue is and where it is (URL, file, or feature).
- Steps to reproduce.
- The possible impact.

We aim to acknowledge reports within 7 days and will keep you updated until the issue is fixed. We are happy to credit you once it is resolved, if you wish.

## Scope

In scope:

- The website and its source code in this repository.
- The content editor (`/keystatic`) and its authentication.
- Forms that send data to the project (for example, suggestion forms).

Out of scope:

- External platforms that listings link to (report those to the platform).
- Fake or scam pages: please use the [report a fake page](https://github.com/HorngFu/Online-in-Cambodia/issues/new?template=report-fake.yml) form instead.

## Supported versions

Only the latest version deployed from the `main` branch is supported.
